# Exemplo de exercício entregue

Este exemplo não vale nota: é só para você ver como fica um arquivo entregue.

- `saida-certa/ex00_dobro.py`: o código funcionou e a saída foi colada no fim.
- `saida-com-erro/ex00_dobro.py`: o código deu erro, e o erro foi colado no fim.

**Os dois contam como entregue:** o arquivo foi alterado e a saída do terminal está colada embaixo de `# SAÍDA:`, mesmo a que deu erro.
